# ต้องมีทั้งสิทธิ์จากลูกค้าและการมอบหมายในสำนักงาน

Phase 10 ให้ Client Organization ออก Firm Access Grant แก่ Accounting Firm Organization และให้สำนักงานกำหนด Client Assignment ของพนักงาน แทนการสร้าง Membership ของพนักงานทุกคนในทุก Client Organization วิธีนี้ลดการจัดการสมาชิกซ้ำ แต่ต้องตรวจ grant, assignment, Membership ของสำนักงาน และสิทธิ์ต่อข้อมูลลูกค้าปัจจุบันทุกครั้ง; Firm Plan หรือ assignment อย่างเดียวให้สิทธิ์อ่านข้อมูลลูกค้าไม่ได้
