# ให้ User เข้าร่วมได้หลาย Organization ผ่าน Membership

User หนึ่งรายเข้าร่วมได้หลาย Organization และ Organization หนึ่งแห่งมี User ได้หลายรายผ่าน Membership ผู้สมัครเองที่ไม่มี invite ต้องสร้าง Organization แรก ส่วนผู้ที่เข้ามาทาง invite จะเข้าร่วม Organization นั้นโดยไม่สร้าง personal organization อัตโนมัติ เพื่อให้ tenant boundary ชัดและไม่สร้างข้อมูลที่ผู้ใช้ไม่ได้ขอ
