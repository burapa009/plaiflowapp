# ใช้ Organization role แบบคงที่สามระดับ

Phase 1 ใช้ Owner, Admin และ Member โดยแต่ละ Organization มี Owner หนึ่งรายและมี Admin หรือ Member ได้หลายราย Owner โอน ownership ได้แต่ leave หรือ delete ตนเองไม่ได้ก่อนโอนสำเร็จ และยังไม่สร้าง custom role หรือ permission editor เพื่อลดความซับซ้อนของ authorization surface
