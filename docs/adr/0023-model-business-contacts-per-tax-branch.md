# สร้าง Business Contact แยกตามสาขาภาษี

หนึ่ง Business Contact แทนบุคคลหรือนิติบุคคลหนึ่งสาขาภายใน Organization และใช้ Country, Tax ID กับ canonical branch identity เป็น strong duplicate key โดยสำนักงานใหญ่ไทยใช้ `00000`, สาขาใช้รหัสห้าหลัก และกรณีไม่ระบุสาขาใช้ค่า canonical ที่ไม่เป็น `NULL` เราไม่แยก Company กับ Branch เป็นคนละตารางใน Phase 3 เพราะการนำเข้า การค้นหา และการเลือกคู่ค้าในเอกสารต้องอ้างปลายทางภาษีที่แน่นอน ขณะที่โมเดลแม่บริษัทและหลายสาขาจะเพิ่มความซับซ้อนก่อนมี use case ที่ต้องรวมข้อมูลข้ามสาขา
