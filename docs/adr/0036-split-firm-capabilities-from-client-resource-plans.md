# แยก capability สำนักงานจากทรัพยากรของลูกค้า

Accounting Firm Plan กำกับ portfolio, งานตรวจที่มอบหมาย และ multi-client export ของสำนักงาน ส่วน Client Organization Plan กำกับการรับเอกสาร, OCR และ Google Drive ของลูกค้านั้น แม้ลูกค้าใช้ Free ก็อาจรับบริการสำนักงานได้เมื่อ Client Organization อนุมัติ Firm Access Grant และพนักงานมี Client Assignment กับสิทธิ์ต่อข้อมูลปัจจุบัน การแยกนี้หลีกเลี่ยงการบังคับลูกค้าอัปเกรดเพื่อใช้บริการสำนักงาน โดย Plan ใด ๆ ไม่แทน authorization
