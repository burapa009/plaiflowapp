# แยก provider configuration ตาม environment และวัตถุประสงค์

แต่ละ environment ใช้ LINE Provider ของตนเองและวาง LINE Login channel กับ Messaging API channel ของ environment เดียวกันไว้ใต้ Provider นั้นเพื่อให้ user ID เชื่อมโยงกันได้ ส่วน Google แยก Cloud project ตาม environment และแยก project/OAuth client ของ Login ออกจาก Google Drive Connector เพื่อให้ consent, token lifecycle และการ revoke Drive ไม่กระทบ Login โดย Drive Connector ขอเพียง `openid email drive.file` แบบ offline ส่วน Google Login ขอเพียง `openid email profile` แบบ online โดยไม่ขอ refresh token, Drive scope หรือ `include_granted_scopes`
