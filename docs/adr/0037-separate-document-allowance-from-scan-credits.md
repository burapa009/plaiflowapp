# แยกโควตารับเอกสารออกจากเครดิตสแกน

Document Allowance นับ Document ที่ Organization รับใหม่ โดย Plan ชำระเงินออกยอดใหม่ทุกเดือนและยกยอดที่เหลือได้สูงสุดตามอายุสองปี ส่วน Free ไม่สะสมยอด; Scan Credit เป็นยอดซื้อแยกต่างหากที่ใช้หนึ่งหน่วยต่อหนึ่งหน้าที่ OCR สำเร็จและไม่หมดอายุ การแยกยอดทั้งสองทำให้การซื้อเครดิตสแกนไม่เพิ่มสิทธิ์รับ Document และการเปลี่ยน Plan ไม่ลบเครดิตที่ซื้อไว้ แม้ช่วงเปลี่ยน Plan หรือชำระเงินล้มเหลวต้องคำนวณ Document Allowance ตามกติกาอีกชุดหนึ่ง
