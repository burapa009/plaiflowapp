# ใช้ Organization เดิมแทนสำนักงานบัญชี

Phase 10 ใช้ Organization ที่มี Membership ของตนเองเป็นสำนักงานบัญชี แทนการสร้าง Firm entity และระบบสมาชิกชุดที่สอง เพื่อใช้ขอบเขตตัวตนและ Plan เดิมต่อไป Organization ลูกค้ายังคงเป็นเจ้าของข้อมูลของตน; ความสัมพันธ์ที่ลูกค้าอนุมัติจะกำหนดการทำงานข้าม Organization โดยไม่ให้ Plan ของสำนักงานกลายเป็นสิทธิ์เข้าถึงข้อมูลลูกค้า
