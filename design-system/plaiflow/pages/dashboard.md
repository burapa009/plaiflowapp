# Dashboard

ไฟล์นี้กำหนดข้อแตกต่างเฉพาะ Dashboard โดยกฎอื่นให้ยึด `../MASTER.md`

## Navigation

- แสดงเพียง `ภาพรวม` และ `สถานะระบบ`
- ห้ามแสดง feature ในอนาคตแบบ disabled หรือ placeholder

## ภาพรวม

- แสดงจำนวน Inbound Events ใน 24 ชั่วโมง: รับแล้ว, ประมวลผลสำเร็จ, ถูกละเว้น, รอลองใหม่ และล้มเหลว
- ใช้ตัวเลขและข้อความสถานะ ไม่สร้างกราฟใน Phase 0
- เมื่อไม่มี event ให้แสดงคำอธิบายการเชื่อม LINE staging แทนข้อมูลจำลอง

## สถานะระบบ

- แสดงสถานะ API, database และ worker heartbeat
- ทุกสถานะต้องมีข้อความหรือ icon ประกอบ ห้ามสื่อด้วยสีเพียงอย่างเดียว
- การโหลดใช้ skeleton ที่รักษาขนาด ส่วนข้อผิดพลาดต้องมีปุ่มลองใหม่
